# 0010. 일식 · 월식의 한국 가시성은 직접 계산을 허용

- 상태: 확정 (구현은 M7-3)
- 날짜: 2026-10-28

## 맥락

M7-3에 일식 · 월식 일정을 넣기로 했다. 핵심 질문은 "한국에서 보이나"인데, 날짜 목록만으로는 반쪽이다. 출처를 직접 호출해 보니 USNO 일식 연도 목록은 되지만 월식 연도 목록은 404, 지역별 일식은 500이었다. 범위에는 "자체 궤도 계산 엔진 제외"가 있었다.

## 결정

사용자 결정 3개.

1. 대시보드 한 칸이 아니라 **새 메뉴**로 만든다. 칸을 더 붙이면 조잡해 보인다.
2. 화면의 주인공은 **"한국에서 언제 보이나"** 다.
3. "자체 궤도 계산 엔진 제외"는 그대로 두되, **한국 가시성만 공개 출처에 없으면 직접 계산해도 된다**(Skyfield 같은 라이브러리 + NASA/JPL 행성 위치표). 원칙은 지키라고 있지만 진행 상황에 따라 유연하게.

순서: ① 공개 기관 표를 먼저 찾고 ② 없으면 직접 계산 ③ 직접 계산한 값은 공개 자료(NASA 표, 한국천문연구원 안내 등)와 3건 이상 대조한 뒤 쓴다. 세부는 [PLAN](../PLAN.md) M7-3.

## 검토한 대안

- **공개 기관 결과만 쓴다**: 처음 안. "한국에서 보이나"를 줄 출처가 없을 수 있다.

## 감수할 것

유일한 예외라 [REQUIREMENTS](../REQUIREMENTS.md) 3.2절에 표시한다. 계산이 틀리면 정확성이 중요한 화면에서 틀린 값이 나가므로 대조 없이는 쓰지 않는다.
