# 0003. 인증은 세션 쿠키

- 상태: 확정
- 날짜: 2026-08-24

## 맥락

회원 기능의 핵심은 관심 천체 저장 하나고, 서버는 1대 규모다.

## 결정

Django 세션 + `httpOnly` 쿠키 + CSRF. 개발 환경은 Vite 프록시로 같은 출처처럼 만든다([ARCHITECTURE](../ARCHITECTURE.md) 2장).

## 검토한 대안

- **JWT**: 서버가 발급한 토큰을 무효화할 수 없어 로그아웃이 제대로 동작하지 않고, `localStorage`에 두면 XSS에 취약하다. 서버 1대 규모라 무상태의 이점도 없다.

## 감수할 것

- CSRF를 신경 써야 한다. 로그인 후 쓰기는 반드시 실제 브라우저로 확인한다(curl은 Origin을 안 보내 못 잡는다).
- 데스크톱 앱(M8)은 화면과 서버 주소가 달라 쿠키 설정을 바꾸거나 토큰 로그인을 따로 둬야 한다. M8 착수 때 정한다.
