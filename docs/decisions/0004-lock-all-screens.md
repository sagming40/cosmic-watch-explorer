# 0004. 화면 · 조회 API 전체를 로그인 뒤로 잠근다

- 상태: 확정
- 날짜: 2026-10-27

## 맥락

처음 설계는 비회원도 NEO · 외계행성을 탐색할 수 있었다. 로그인 기능이 생기자 주소만 치면 다 보이는 화면을 잠그기로 했다(사용자 결정).

## 결정

**화면 + API를 함께 잠근다.** 둘 다 "기본 잠금"으로 둔다.

- 백엔드: `DEFAULT_PERMISSION_CLASSES = [IsAuthenticatedOr401]`. 공개는 인증 API 4개(`csrf` · `me` · `signup` · `login`)만 `AllowAny`로 명시한다.
- 프론트: `/login` · `/signup` 밖의 라우트를 `ProtectedRoute` 하나로 감싼다.

새 API · 화면은 따로 붙이지 않아도 잠긴다. 덤으로 비로그인 요청은 뷰 전에 401이라 NASA 호출 · 스로틀을 쓰지 않는다.

## 검토한 대안

- **화면만 잠근다**: 빠르지만 `/api/neo/`를 직접 치면 데이터가 다 보인다. 현관만 잠그고 창문 열어 둔 꼴이다.
- **그대로 둔다**: 포트폴리오 면접관이 가입 없이 써 볼 수 있는 장점이 있지만 포기했다.

## 감수할 것

처음 보는 사람은 가입부터 해야 한다. 체험용 계정을 둘지는 배포(M6) 때 정한다.
