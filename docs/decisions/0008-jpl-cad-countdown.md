# 0008. 카운트다운 데이터는 JPL CAD에서 받는다

- 상태: 확정
- 날짜: 2026-10-28

## 맥락

대시보드 "다음 근접 접근까지"에 줄 값이 필요했다. 우리 DB에는 누군가 조회한 날짜만 있다.

## 결정

NASA/JPL Close Approach Data API(`ssd-api.jpl.nasa.gov/cad.api`, 키 없음)에서 받는다. **지금 이후, 지구에서 0.05 AU(19.46 LD) 안쪽 중 가장 먼저 오는 접근 1건.** DB에 저장하지 않고 서버 캐시 6시간. 구현 세부는 [ARCHITECTURE](../ARCHITECTURE.md) 4.2절, `services/jpl_cad.py`.

## 검토한 대안

- **우리 DB에서 고르기**: 안 연 날짜의 접근이 빠지고, 기기마다 DB가 달라 같은 시각에 답이 다르다.
- **1 LD 기준**: 앞으로 365일에 1건뿐이라(10-28 실측) 거의 1년 내내 빈 칸이다.
- **"가장 가까운" 접근**: 와이어프레임의 뜻과 다르다. 0.05 AU는 JPL CNEOS 표 기본값이자 PHA 판정 거리라 대시보드 FAQ와 같은 숫자다.

## 감수할 것

- 궤도가 덜 정해진 천체는 시각이 몇 시간씩 틀린다. 초 단위 숫자 옆에 오차(±)를 반드시 같이 보여 준다.
- JPL 번호와 NeoWs 번호가 달라, 이름으로 우리 DB를 찾고 없으면 상세 링크 대신 그날 목록으로 안내한다.
