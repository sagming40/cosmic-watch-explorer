# 0009. 배포 위치

- 상태: 대기 (AWS 크레딧 이전 결과)
- 날짜: 2026-10-28 (처음 결정), 2026-11-04 (재정비 때 지금 사실로 정리)

## 맥락

처음 추천은 Lightsail 서울 + Route 53 도메인이었는데 계정에서 세 번 막혔다.

- Route 53 도메인 등록 실패(Support 문의 안내).
- 프로젝트 계정은 AWS가 관리하는 조직 소속이라 SCP로 서울이 막히고 시드니만 된다.
- 예전 일반 계정은 크레딧이 없고 유료 플랜이다.

## 결정

**Lightsail 2GB 한 대(Nginx + Gunicorn + MariaDB).** 위치는 크레딧 이전 결과로 정한다: 성공하면 일반 계정 서울, 실패하면 프로젝트 계정 시드니.

- 도메인 `sagming.com`은 Cloudflare에서 10-30에 샀다. Route 53은 쓰지 않고 A 레코드에 서버 IP만 넣는다.
- 공용 계정 · 서버 이사 계획은 전역 `CLAUDE.md` "공용 인프라" 절, 진행 상황은 드라이브의 `2026-11-03_AWS_크레딧이전_케이스_정리.md`가 원본이다. 여기에 옮기지 않는다.

## 검토한 대안

| | 프로젝트 계정 · 시드니 | 일반 계정 · 서울 |
|---|---|---|
| 비용 | 크레딧 $120 | 처음부터 카드 결제 (이전되면 크레딧) |
| 안전장치 | 지출 한도 $30 강제 상한 | 알림(Budgets)만 |
| 한국에서 속도 | 조금 느림 | 빠름 |

처음 하는 배포라 "실수해도 상한에서 멈추는" 시드니를 기본으로 둔다.

- **Vultr**: cbt-journal이 쓰는 방식([cbt-journal 결정 0007] 참고). 전역 계획이 12월부터 AWS라 기본 후보가 아니다.

## 감수할 것

답이 올 때까지 서버 생성을 미룬다. 그동안 배포 전 백엔드 점검을 먼저 한다. 답이 와서 위치가 확정되면 이 파일 상태를 바꾸고, 뒤집으면 새 파일을 만든다.
