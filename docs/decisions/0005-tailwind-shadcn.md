# 0005. Tailwind CSS v4 + shadcn/ui 지금 도입

- 상태: 확정 ("v1.0 이후" 결정을 같은 날 번복)
- 날짜: 2026-10-27

## 맥락

순수 CSS로 화면을 짜다 보니 코드가 길고 투박했다. 화면 목업을 다시 만들기로 하면서, 남은 화면이 대부분인 지금이 전환 비용이 가장 싼 시점이었다.

## 결정

Tailwind CSS v4 + shadcn/ui. 색은 그대로 토큰 7개만 진짜 값이고, shadcn 역할 이름은 전부 그 토큰을 가리키게 연결한다([DESIGN](../DESIGN.md) 2.5절). 사용 규칙은 CLAUDE.md 3.4절.

## 검토한 대안

- **v1.0 이후로 미룬다**: 처음 결정. 그러면 목업과 실제 화면을 두 번 만든다.
- **순수 CSS 유지**: 코드가 길어지고 버튼 · 카드 같은 부품을 직접 만들어야 한다.

## 감수할 것

- 옛 `index.css` 규칙을 `@layer`로 옮겨야 한다. 레이어 밖 CSS는 유틸리티를 이겨서 클래스가 무시된다.
- Windows에서 shadcn CLI가 엉뚱한 npm 패키지 `cn`을 설치한다. 추가할 때마다 CLAUDE.md 3.4절 절차를 따른다.
